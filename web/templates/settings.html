Examples: auto, hci0, hci1. The collector must be restarted after changing this setting.

How offline lookup works

  1. RF Monitor checks the local databases first.
  2. The captured MAC address can be checked against the local IEEE databases.
  3. Bluetooth manufacturer/company IDs can be checked against the local Company ID database.
  4. Internet access is only required when an online fallback is explicitly used.
  5. Updating these files does not require restarting the BLE collector.
